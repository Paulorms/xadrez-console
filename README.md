# Xadrez Console

Um jogo de xadrez funcional que roda direto no terminal. Fiz esse projeto para consolidar conceitos de Programação Orientada a Objetos (POO) e arquitetura de software, separando a lógica genérica de um tabuleiro das regras específicas do xadrez.

## Funcionalidades

Regras oficiais: Movimentação das peças, sistema de turnos, xeque e xeque-mate.

Código limpo: Divisão clara entre a camada do tabuleiro e a lógica do xadrez.

Robusto: Tratamento de jogadas inválidas com exceções personalizadas para o jogo não quebrar do nada.
